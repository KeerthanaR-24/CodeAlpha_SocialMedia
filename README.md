# CodeAlpha Social Media

A simple social media web application developed using Django as part of the CodeAlpha Full Stack Development Internship.

## Features

- User registration and login
- User profile pages
- Create posts
- Edit posts
- Delete posts
- Upload images with posts
- Like and unlike posts
- Comment on posts
- Follow and unfollow users
- Followers list
- Following list
- Personalized user feed
- SQLite database

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite
- Pillow
